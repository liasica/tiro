# Tiro

把飞书妙记自动整理成会议纪要。

Tiro 定时检查授权用户名下的新妙记，取回逐字稿，交给 OpenAI 格式的模型接口按模板写成纪要，在该用户的飞书云空间创建文档，再由机器人私聊把链接发给本人。

## 运行

需要 Go 1.27、Node 24 与 pnpm。

```bash
make all
```

```bash
./bin/tiro
```

启动后打开 <http://localhost:8476>。首次打开进入初始化向导：

1. 用飞书扫码创建应用
2. 用飞书扫码授权，第一个授权的人成为管理员
3. 填写模型接口的地址、模型名与密钥

完成后进入后台。之后新生成的妙记会在几分钟内出现在「纪要」列表里并自动生成文档。

## 启动参数

| 参数 | 环境变量 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `-addr` | `TIRO_ADDR` | `:8476` | 后台的监听地址 |
| `-data` | `TIRO_DATA_DIR` | `data` | 数据目录，存放 SQLite 数据库 |

其余配置都在后台的「设置」页里：模型接口、检查间隔、云空间文件夹名、逐字稿最短字数、术语表、纪要提示词。

数据目录里的 `tiro.db` 保存飞书应用凭据、用户令牌与模型接口密钥，备份与迁移时整目录带走。

## Docker

```bash
docker build -t tiro .
```

```bash
docker run -d --name tiro -p 8476:8476 -v tiro-data:/data tiro
```

## 后台

- **纪要**：每条妙记的处理状态、生成的纪要预览与飞书文档链接；管理员可以粘贴妙记链接手动添加，也可以重新生成
- **成员**：已授权的成员、授权状态，以及是否为其自动生成纪要
- **设置**：模型接口、运行参数、术语表、纪要提示词

其他成员打开后台扫码登录即完成授权，此后名下的新妙记自动生成纪要。成员只能查看自己的纪要；设置、成员管理、手动添加与重新生成只有管理员可用，管理员可以在「纪要」页切换查看全部成员的记录。
